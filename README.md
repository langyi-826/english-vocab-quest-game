# 中小学生英语背单词闯关游戏

一位家长做给自己孩子用的英语背单词闯关游戏生成器——家长零技术基础也能用。回答几个大白话问题（孩子几年级、哪个城市上学、课本什么版本），几分钟就能生成一个孩子愿意天天打开的闯关游戏。

> GitHub 仓库建议英文名：`english-vocab-quest-game`

## 它解决什么问题

孩子不爱背单词、背了就忘、家长催一次吵一次。这个游戏不靠"多背几遍"，靠**阶段性激励**：

- 每关只放 10 个词，先看闪卡，再答拼写和选择题，几分钟拿下一关，容易尝到"我做到了"
- 每关按正确率给 1-3 星，星级梯度拉开（满星约 104 碎片、两星约 47、一星约 23），必须真掌握才拿得到大份碎片，刷关攒不出分
- 攒够碎片换奖励，奖励清单由家长自己填——换什么、多少碎片、分几档全由家长定
- 改奖励要输家长自己设的安全密码，密码跟进度一起保存，换电脑不丢

## 功能清单

- 多孩子独立档案（各自进度、各自奖励、互不干扰，可新建/修改/删除）
- 单词发音、字典卡（音标、词性、例句）、拼写与选择两种题型、错词收集
- 连续打卡、8 枚徽章、6 级称号
- 阅读与作文进阶挑战
- 进度自动保存，关掉再打开不丢；换新版本自动接管旧进度，不覆盖

## 怎么安装

把本文件夹整个复制到你的 skills 目录，例如：

```
~/.workbuddy/skills/english-vocab-quest-game/
```

- `SKILL.md`：主文件（含完整的操作流程和话术）
- `assets/game_template.html`：游戏模板
- `references/奖励设计指南.md`：奖励设计参考
- `scripts/build_game.py`：生成脚本

四部分都要保留，缺了生成不了游戏。

## 怎么用

在对话框里直接用大白话说，例如：

- "给我三年级的孩子做一个背单词闯关游戏，人教版"
- "孩子不爱背单词，帮我做个能攒碎片换奖励的游戏"
- "这是我孩子课本的单词表（照片），照着做一个闯关游戏"

工具会先问你几个问题、确认词库，再生成游戏，最后教你怎么打开。

## 交付后怎么用

生成的是一个 **HTML 单文件**，存到电脑或手机上，**双击打开就能玩**，不依赖网络。

注意两点：① 不要在聊天窗口/预览里直接点开，要先存到本地再打开，否则进度存不住；② 用同一个浏览器打开，别今天这个明天那个。
